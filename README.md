# Sammunat LLC - Modern React Landing Page

A professional, responsive landing page built with React, Vite, and Tailwind CSS for Sammunat LLC. This project showcases modern web development practices with a clean, scalable architecture.

## 🚀 Features

- **Modern React Architecture**: Built with React 19 and functional components
- **Lightning Fast**: Powered by Vite for instant development and optimized builds
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Interactive Navigation**: Mobile-responsive navbar with smooth animations
- **Component-Based**: Modular, reusable components for easy maintenance
- **Professional UI**: Clean, modern design with gradient backgrounds and hover effects
- **Optimized Performance**: Fast loading and smooth user experience

## 🛠️ Tech Stack

- **Frontend**: React 19.2.0
- **Build Tool**: Vite 7.2.4
- **Styling**: Tailwind CSS 4.1.18
- **Icons**: Lucide React
- **Linting**: ESLint with React-specific rules
- **Package Manager**: npm

## 🚦 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd sammunat_LLC
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the application
   Deploy link `https://sammunat-llc-phi.vercel.app/` to view the application

## 📜 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally

## 🔧 Customization

### Styling
The project uses Tailwind CSS for styling. You can customize:
- Colors in the gradient backgrounds
- Typography and spacing
- Component layouts and animations

### Content
Update component content by editing the respective files in `src/components/`:
- Company name and branding in `Navbar.jsx`
- Hero messaging in `Hero.jsx`
- Feature descriptions in `Features.jsx`

### Configuration
- Vite configuration: `vite.config.js`
- ESLint rules: `eslint.config.js`
- Tailwind settings: Configured via `@tailwindcss/vite` plugin
